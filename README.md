# PINN-Fluid-Dynamics-1D-Burgers-Equation
A Physics-Informed Neural Network (PINN) built in PyTorch to solve the 1D Burgers’ Equation. By embedding Navier-Stokes physics into the loss function via automatic differentiation, the model captures non-linear shock wave formation. This project demonstrates the power of Scientific AI to solve complex PDEs with mathematical rigor and minimal data.
